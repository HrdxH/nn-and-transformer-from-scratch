# Neural Network & Transformer From Scratch

A 2-week project building a feedforward neural network (NumPy, manual
backprop) and a small transformer/mini-GPT from scratch, with
literature-grounded design notes.

## Part A: Neural Network from Scratch
- Fully connected network (784 → 32 → 32 → 10), trained on MNIST
- Manual forward pass, backpropagation, and gradient descent (no autograd)
- 90.4% test accuracy
- See `DESIGN_NOTES.md` for architecture decisions and reasoning
